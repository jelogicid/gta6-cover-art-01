Noto Sans, Black weight (NotoSans-Black.ttf)
============================================

The one typeface the app ships. Every headline, caption, panel plate and control label is set in it; the
condensed poster lettering is the same face drawn with a horizontal scale of 0.79 in canvas, so no second
font file is needed and nothing falls back to a system font.

  Source family: Noto Sans (latin, greek, cyrillic)

The OFL allows the font to be bundled and redistributed with this app as long as the copyright notice and
the license travel with it, which is why OFL.txt sits here. The font is not renamed or modified; the
horizontal squeeze is applied at draw time, not to the file.

Nothing here comes from a game, a game publisher or a commercial type foundry.
